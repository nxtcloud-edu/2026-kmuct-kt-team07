# 사진·구매·모바일 개선 기록

2026-09-20, 배포 없이 로컬 앱에 적용.

## 사진

- 원문 OCR은 보존하고 비교에만 NFKC를 적용한다. 전각 영문·숫자·하이픈도 비교할 수 있다. 불확실 문자 치환과 정확 일치 규칙은 유지한다.
- 라벨 사진은 최대 2400px/품질 92, 전체·부품 사진은 기존 1600px/품질 85다. EXIF 제거, 회전, 픽셀·업로드 크기 제한을 유지하며 AI 입력 3.75MB 상한을 검사한다. 이미 작은 원본은 확대하지 않는다.
- 관찰 프롬프트에서 모델 코드와 용량을 역할별로 분리하고 작은 글자를 살피도록 명시했다. 누락 글자 추측, 호환성 판단, 지시문 실행은 계속 금지한다.
- 정확한 모델 일치가 없을 때만 선명한 브랜드·용량으로 `photoHints`를 제공한다. L↔ml은 정확한 단위 환산만 하며 oz↔ml은 추정하지 않는다. 서로 다른 브랜드·용량이 함께 읽히거나 알 수 없는 브랜드가 섞이면 좁히지 않는다.
- 참고 후보는 모델 인식 결과와 별도 필드이며 자동 선택하지 않는다. 화면에 참고 후보임을 밝히고 명시적 제품 선택 뒤에만 부품을 표시한다. 후보 필터를 풀면 전체 제품을 볼 수 있다.
- 결과 상단에 재촬영 안내·불분명한 문자 안내·라벨 추가 버튼을 제공한다. 사진 역할은 기본 전체→부품→라벨 순서이며 사용자가 바꿀 수 있다.

## 구매

- 국내 최근 주문 가능 부품 필터, 정확한 색상/규격 옵션, 별도 확인 시각, 품절/판매 종료 링크 문구를 추가했다.
- 상태는 24시간 후 재확인으로 바뀐다. 원본 이력과 적용 여부는 유지한다. 시각을 확인하지 않은 과거 자료는 날짜만 표시한다.
- 실제 구매 완료나 물리적 장착·누수 시험은 하지 않았다. 확인 범위는 국내 판매 페이지의 옵션·주문 버튼이다.

## 모바일

- 카메라 촬영 진입과 라벨 전용 업로드, 사진 준비 체크리스트를 추가했다. `capture=environment`는 지원 기기에서 후면 카메라 선택을 요청한다. 실제 동작은 기기/브라우저에 따른다.
- 모바일 주요 버튼·구매 링크·사진 삭제 버튼은 최소 44px 터치 영역, 입력/선택 필드는 16px 글자 크기를 적용했다. 사진 썸네일은 잘리지 않게 표시한다.
- 기존 JPG/PNG/WebP만 허용한다. HEIC 직접 업로드는 미지원이며 형식 안내를 표시한다.

## 검증 범위

- `npm test`: 자동 테스트 56개. 전각 모델명, 브랜드·용량 후보/충돌, 고해상도 라벨/EXIF, 주문 상태 만료, 명시적 제품 선택을 포함한다.
- `npm run build`: 타입 검사와 클라이언트/서버 빌드.
- `node --env-file-if-exists=.env --import tsx scripts/evaluate-photos.ts --live`: 실제 API 호출 3건, 합성 라벨 2장과 기존 공개 물병 사진 1장. 세 사례 통과. 이는 실제 제품 사진 데이터셋의 정확도나 변경 전후 비교 수치가 아니다. 결과는 `artifacts/photo-evaluation/report.json`.
- Chrome 확장 프로그램의 파일 URL 접근 제한으로 자동 파일 선택 완료는 검증하지 못했다. 실제 multipart 파일 처리와 역할 전달은 서버 통합 테스트에서 검증했다. 실제 휴대폰 카메라·사진첩 테스트는 별도 필요하다.
- 민감한 사용자 사진을 사용하지 않았으며 API 키는 산출물에 기록하지 않았다. 공개 예제 사진의 기존 라이선스는 `tests/fixtures` 자료를 따른다.

- 실제 브라우저의 공개 예제 분석 1건도 완료: 빛 반사 재촬영 안내와 미확정 제품 상태를 확인했다. 390px 모달/구매 결과, 320px 결과 화면에서 가로 넘침 없음, 16px 입력 글자와 44px 이상 주요 터치 영역을 확인했다. 세부 기록: `artifacts/photo-purchase-mobile-verification.json`.

## 동시 디자인 작업 통합

별도 `전면적인 UI·UX 개선` 작업이 같은 App.tsx 및 기본 스타일을 수정 중이다. 기능 스타일은 `client/photo-purchase.css`로 분리하고 main.tsx에서 기본 스타일 뒤에 불러온다. 입력 영역이 접히는 새 디자인에 맞춰 사진 추가 시 `setFinderOpen(true)`로 입력을 다시 연다. 검증 당시의 기본 디자인과 이후 전면 디자인은 구분해야 하며, 전체 디자인의 최종 반응형 검수는 해당 작업에 포함된다.
