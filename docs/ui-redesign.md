# UI/UX 개선 기록

기존 React·Vite·Lucide와 네이티브 dialog를 유지하고, API·데이터 계약·세션·기록 처리에는 별도 재작성을 하지 않았다. 작업 중 공유 작업 공간에서 추가된 제품군·구매 필터 코드는 보존했다.

## 기존 화면의 문제

- 큰 소개 영역과 장식용 물병 일러스트 아래에 핵심 입력이 배치되어 실제 찾기까지의 거리가 길었다.
- 안내, 입력, 카탈로그, 결과에 비슷한 시각적 비중을 주어 다음 행동을 발견하기 어려웠다.
- 제품을 선택한 뒤에도 입력 영역과 소개가 길게 남고, 화면 스크롤 위치가 결과 중간에 남을 수 있었다.
- 글자 크기·간격·색상·라운드가 반복 하드코딩되어 화면 간 규칙을 관리하기 어려웠다.

## 콘셉트와 화면 구조

**내 물건의 모델과 부품을 차근히 대조하는, 정돈된 부품 안내 데스크.**

1. 첫 화면은 소개·실제 카탈로그 수치와 찾기 폼을 약 40:60 비율로 배치한다. 숫자가 붙은 단계와 얇은 구분선이 반복되는 시각적 모티프다.
2. 사진·모델명 입력에 집중한다. 선택 입력과 촬영 가이드는 펼쳐서 확인하며, 카탈로그 진입은 보조 행동으로 둔다.
3. 결과를 열면 입력을 접고 선택한 제품, 진행 단계, 적용 근거의 상태별 수량을 상단에 표시한다. 다시 찾기로 입력을 복원할 수 있다.
4. 카탈로그는 반복 카드 대신 제품별 행으로 정리한다. 독립적으로 비교할 부품 결과에만 카드를 사용한다.
5. 정품·조건부 적용·적용 제외·판매 상태는 원래 의미와 출처를 유지한다. 실시간 재고나 실물 장착 검증으로 확대 해석하지 않는다.

## 공통 규칙

- 브랜드: 초록 `#245b43`, 본문 `#253c33`, 보조 본문 `#647068`.
- 배경: 따뜻한 중립색 `#f6f5f0`; 입력·비교 영역은 흰색.
- 간격: 8px 기반, 4px 보정. `--space-*` 변수로 관리.
- 반경: 입력·버튼 4px, 독립 패널 8px. 그림자는 dialog·알림에 제한.
- 타이포그래피: 시스템 한국어 글꼴, 본문 15px, 제목·설명·메타 정보 단계 구분. 숫자는 표 폭이 일정한 숫자 스타일.
- 인터랙션: 180ms 색·테두리 전환, 초록색 포커스 링, disabled·loading·empty·error·success 상태. 모션 감소 환경 존중.
- 재사용: 기존 ProductCatalog·Modal·MeasurementGuide를 유지하며 CategoryPicker를 추가해 같은 부품 선택 규칙을 입력·결과에 적용.

## 반응형

- 1440px: 소개와 폼을 비대칭 배치.
- 1024px: 같은 구조에서 폭·간격 축소.
- 768px: 소개와 실제 등록 수치를 간략화하고 입력을 전체 폭으로 배치.
- 360px: 한 열 구조, 부품 버튼 줄바꿈, 전체 폭 선택 버튼, 네이티브 모바일 입력, 화면 안에서 스크롤되는 모달.
- 긴 제품명과 설명에 줄바꿈을 허용하고 폼·그리드에 최소 폭 제약을 제거.

## 후속 개선

- 대표 제품군별 실물 사진을 확보하면 결과에서 모델·외형 대조를 더 쉽게 제공할 수 있다.
- 실제 휴대폰의 카메라 권한·촬영과 Safari·Android에서 추가 기기 검증이 필요하다.
- 카탈로그·API의 별도 확장 작업이 완료되면 각 제품군의 대표 시나리오를 다시 통합 검증하는 것이 좋다.

## 실행 검증 결과

- `npm run check`: 카탈로그 검사, 기존 테스트 56개, 서버·클라이언트 타입 검사, 배포 빌드 통과. 출력은 `artifacts/ui-check.log`에 보관.
- Chrome에서 360·768·1024·1440px 반응형과 가로 넘침 여부 확인. 첫 화면·결과 스크린샷은 `artifacts/ui-redesign/`에 보관.
- 날진 모델명 검색 → 32oz 선택 → 정품·조건부 대체품 → 적용 제외 확인 → 패킹의 빈 결과 → 규격 저장 확인.
- 긴 규격 문자열과 큰 숫자를 입력해 레이아웃·저장·문의 초안 반영을 확인.
- 문의 초안 복사, 최근 기록, Escape로 모달 닫기, 필터 초기화, 검색 결과 없음 확인.
- 결과 JSON이 실제 내려받아졌으며 선택 제품·부품 종류·저장된 답변이 포함됨을 확인.
- 공개 예제 사진 1회의 실제 AI 분석에서 대기·관찰 결과 표시 확인. 이 검사는 연결과 화면 흐름 확인이며 모델 식별 정확도 검증은 아님.
- 공유 코드의 API 확장 후 미리보기 서버를 재시작하고 최신 요청으로 모델명 검색·제품 선택을 재확인.
- 브라우저 확장에 파일 URL 접근 권한이 없어 자동 파일 업로드 검증은 완료하지 못함. 파일 선택·드래그·실제 카메라 촬영은 추가 수동 검증 항목.
- 미리보기는 기존 서버와 별개로 `http://localhost:3012`에서 실행. 기존 개인 기록과 분리한 테스트용 저장소 사용.
