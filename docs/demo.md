# 시연 가이드

사용자는 시연할 실물 사진이 없어 제품 사진을 Google에서 구해 업로드할 예정이다. 서비스에 Google 이미지 검색·가져오기 기능을 추가하라는 요청은 아니다.

## 준비할 제품

가장 간단한 카탈로그 사례는 **Nalgene 32oz Wide Mouth Bottle**이다. Google에서 `Nalgene 32oz Wide Mouth Bottle` 또는 `날진 와이드마우스 32oz`로 찾아 제품 전체와 용량·브랜드가 보이는 사진을 준비한다. 실제 사진의 모델·용량은 [공식 제품 페이지](https://nalgene.com/product/32oz-wide-mouth-bottle/)와 대조한다.

사진만 보고 무조건 식별되는 기능이 아니다. 라벨에 모델명이 없거나 글자가 흐리면 “일치 모델 없음”이 정상일 수 있다. 사진 속 제품과 실제로 일치할 때만 등록 제품을 수동 선택한다. 사진 출처의 이용 조건을 확인하고, 공개 발표 자료에는 출처를 함께 표기한다.

## 2~3분 시연 순서

1. `npm start` 후 `http://localhost:3001`을 연다.
2. “사진으로 찾기”에서 사진 1~4장을 추가한다. 각 사진의 역할을 제품 전체·부품/장착부·라벨 중에서 선택한다. “뚜껑”을 선택하고 부품 찾기를 누른다.
3. 분석 결과의 “사진에서 확인한 내용”을 펼친다. 사진에 보이는 특징과 글자를 보여주고 AI가 호환 여부를 직접 결정하지 않는다고 설명한다.
4. 공식 페이지와 사진을 대조한 뒤 실제 제품에 맞는 용량을 고른다. Nalgene 32oz를 선택하면 정품 Wide Mouth Cap, 조건 확인이 필요한 humangear capCAP+, 적용 제외된 16oz 전용 캡이 구분된다.
5. “적용 근거 확인”으로 출처를 확인하고 판매 페이지와 검색 결과 링크가 다름을 보여준다.
6. 패킹 탭으로 바꿔 미등록 상품을 허위 추천하지 않는 흐름을 보여준다. 규격을 모르면 빈칸으로 두고 제조사 문의 초안을 확인한다.
7. “최근 찾기”에서 이어보기, “결과 저장”으로 개인 기록 내려받기를 보여준다.

## 사진 준비 전에도 가능한 확인

- **모델명으로 찾기 → 날진 와이드마우스**: 용량별 후보와 구매·대체 경로를 바로 확인한다. AI 분석을 실행하지 않는다.
- **공개 예제 사진으로 분석 체험**: CC BY-SA 4.0 공개 물병 사진을 실제 API로 보낸다. 이 사진은 브랜드·모델 라벨이 없어 알려진 카탈로그 제품과 같다고 선택하면 안 된다. 미확인 처리 흐름을 보여주는 용도다.
- **Hydro Flask Wide Mouth → 32oz → 뚜껑**: capCAP+의 조건부 적용과 구형 capCAP의 명시적 적용 제외를 비교한다. Hydro Flask 사이트는 자동 HTTP 검사를 차단하므로 시연 전 직접 브라우저 접근을 확인한다.

## 발표에서 사실대로 설명할 내용

“사진에서 관찰한 정보로 제품을 확인하고, 검수한 자료를 바탕으로 정품·대체품·검색·문의 경로를 안내합니다.”

실물 장착 결과를 아직 확보하지 않았으므로 “대체품으로 수리를 완료했다”, “모든 물병에 호환된다”, “AI가 상품을 실시간으로 찾아 검증했다”라고 설명하지 않는다. 장착 기록 기능은 준비되어 있으며 팀이 직접 확인한 조건을 기록할 수 있다.

## 국내 구매 경로 시연

- 등록 제품 둘러보기 → `써모스 JNL 505K` 검색 → 제품 선택 → 패킹: JNL 패킹세트와 국내 공식몰 링크 확인.
- `FHL-550K` 선택 → 빨대: 550ml 옵션만 안내하며 400ml 옵션을 추천하지 않는지 확인. 판매 페이지에서 용량 옵션을 직접 선택해야 한다.
- 브랜드 `써모스` + 용량 `800ml` → JOW-800K: 공용 패킹과 용량별 마개를 구분한다.
- 패킹 공용 여부를 근거로 다른 용량의 마개까지 공용이라고 설명하지 않는다.


추가 브랜드 사례:

- `킨토 워터보틀 950ml` → 뚜껑: 950ml 전용과 적용 제외된 300/500ml·워터텀블러 캡을 구분한다.
- `킨토 플레이 텀블러 480ml` → 빨대: 480ml 전용 부품의 적용 근거와 확인 당시 품절을 함께 표시한다.
- `조지루시 SM-VB72` → 뚜껑: 공식 부품 BB780807L 및 모델 계열별 색상 옵션 안내를 확인한다.
