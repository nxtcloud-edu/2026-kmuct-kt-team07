# 이번 구현에서 확정한 범위

원래 첨부 설계서는 개발 제안이며 기술 선택·일정·데이터 수량은 목표값이었다. 이번 작업은 기존 TypeScript 관찰 모듈과 사용자가 입력한 제공 AI API를 기반으로, 해커톤에서 실제로 실행할 수 있는 단일 서버 웹 앱을 완성하는 범위로 구현했다.

| 항목 | 이번 구현 |
|---|---|
| AI 공급자 | 사용자 변경대로 제공 API. AWS Bedrock 직접 호출 안 함 |
| 웹/API | 기존 Node 모듈을 재사용하는 React/Vite + Express |
| 저장소/큐 | 별도 클라우드 계정 없이 동작하는 단일 프로세스 SQLite. 재시작·중복·소유권 처리 포함 |
| 상품 범위 | 제품 20개·부품 22개로 확장. 국내 써모스 16개 모델과 용량별 적용 관계를 확인한 정품 부품 추가 |
| 대체 경로 | 정품·타사 근거 카드, 범용 규격·중고 검색·수리 문의로 확장 |
| 사진 | 사용자가 Google에서 시연 사진을 준비해 기존 업로드로 사용. Google 이미지 검색을 앱에 추가한 것이 아님 |
| 관리자 작업 | 로컬 카탈로그 검증·가져오기·변경 이력·링크 검사 CLI. 웹 관리자 화면은 없음 |
| 문의 | 공식 제조사 페이지와 복사 가능한 초안. 서비스 운영자에게 접수·답변을 약속하는 검수 티켓 기능은 없음 |
| 후기 | 익명 개인 기록. 실제 장착·검수·공개 동의를 하지 않은 사례를 공개 추천 근거로 쓰지 않음 |
| 규격 | 카테고리별 도식과 확인 메모. 실제 상품별 수치 허용오차가 확보되지 않아 치수만으로 자동 호환 판정하지 않음 |
| 확장 | 회원 계정, 공개 후기, 다중 서버, 웹 관리자, 대규모 카탈로그, 실시간 웹 수집은 후속 운영 확장 범위 |

이번 검증은 기능 동작과 입력·출력·접근 제어의 확인이다. 제품 인식 정확도, 실제 수리 성공률, 사용자 조사 결과를 얻었다는 뜻이 아니다. 공개 출시 여부는 시연 가능한 상태와 별도로 판단한다.
